# Probe exact pure-Go streaming candidates on both platforms

## Description
Build pinned pure-Go adapters against the shared range and cache substrate and reject missing codec or security behavior explicitly.

## Scope
Integrate each shortlisted exact candidate behind one node adapter on Windows and macOS. Use incremental authenticated ranges and bounded rings, coordinator-time schedule, pause, random VBR seek, resume, drain and cancellation with no render I/O. Run the hostile decoder corpus, race checks and every shared format, memory, start, seek, skew and architecture gate. Record CPU, binary size, maintenance and unsupported codec or container behavior.

## Acceptance Criteria
A pure-Go combination passes the identical Windows and macOS hard gates with pinned versions and artifacts, or every failure is concrete rejected-option evidence. No C wrapper is mislabeled pure Go, no full-file allocation or crash on hostile input is tolerated, and the adapter seam remains usable by the streamed-track story.
