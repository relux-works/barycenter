# Wire minimal capabilities and truthful localized product copy

## Description
Make packaged declarations and RU or EN strings match the explicit-action self-contained product without broad or surprise permissions.

## Scope
Add only the Windows microphone DeviceCapability and platform-spike-approved declarations, plus macOS NSMicrophoneUsageDescription and any sandbox entries proven necessary. Keep permission prompts behind explicit Record and preserve cue or file playback after denial. Consume the shared localized label vocabulary for Create, Join, Try locally, routing, history, report and optional integrations. Remove Spotify-first or Telegram-required claims, broad filesystem access and silent Accessibility expansion. Validate package schemas and run WACK or platform equivalents.

## Acceptance Criteria
The signed package declares only capabilities used by shipped features, permission is never requested at launch, denial leaves the reviewer path through builtin cue and files usable, and RU and EN package and UI text describe equivalent functionality. WACK and manifest validation pass, no broad capability slipped in, and optional integrations are plainly optional.
