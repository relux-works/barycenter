# Freeze the Phase 2 gate matrix and lab contract

## Description
Define immutable thresholds, environments, build provenance and sanitized evidence before final proof begins.

## Scope
Map B1-B7, sections 17-18 and 20.5-20.6 to exact commands, sample counts, clocks, fixtures, build and package hashes, feature-flag state and raw artifacts. Freeze Windows-Windows, Windows-macOS and macOS-macOS, Phase 1 mixed nodes, three or eight Barycenters and five or twenty Pulsars, one-hour and two-hour media, production-shaped migration and previous-binary rollback, quota and incident definitions, seven consecutive 24-hour beta windows, privacy or participant consent and artifact sanitization. Name real hardware, homes, operators, credentials and external authority as blockers.

## Acceptance Criteria
Every acceptance and reviewer task starts with the same dated pass or fail criteria, topology, fixture hashes and evidence paths. Exact 5 s start, 3 s seek, 100 ms skew, 200 MiB RSS, bounded duration, load and seven-day rules are fixed. Missing lab, participant, beta or authority input is visible and no later task can lower a gate or invent evidence.
