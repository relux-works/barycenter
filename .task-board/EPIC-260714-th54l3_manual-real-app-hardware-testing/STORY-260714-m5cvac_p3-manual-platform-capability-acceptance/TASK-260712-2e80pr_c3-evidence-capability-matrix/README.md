# Run the real C3 acoustic matrix and publish capability claims

## Description
Produce the final real-hardware objective and blinded-listening evidence and an honest platform or route capability matrix.

## Scope
On dated supported Windows and macOS hardware run calibrated speaker and headphone cases across Windows to Windows, Windows to macOS and macOS to macOS, including far-end-only, near-end-only, double-talk, route change and accepted degraded or unsupported conditions. Record build and fixture hashes, objective metrics, blinded listening results, screenshots, resource and teardown evidence, exact user-facing claims, feature flags and rollback. Hand only the seven-day soak and combined promotion decision to Phase 3 acceptance.

## Acceptance Criteria
C3 is reproducibly proven for every claimed accepted route with no intelligible return echo and preserved near-end speech. Degraded and unsupported combinations are explicit, both ceilings and capture indicators are proven, no missing hardware is called passed and the evidence pack is independently reviewable from raw sanitized artifacts.
