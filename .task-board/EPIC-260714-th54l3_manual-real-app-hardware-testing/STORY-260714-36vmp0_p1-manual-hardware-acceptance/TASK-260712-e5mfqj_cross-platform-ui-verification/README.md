# Cross-platform UI accessibility, DPI and acceptance evidence

## Description
Produce the verification coverage and acceptance evidence for the Phase 1 UI and local capture path.

## Scope
Run platform-appropriate tests and hands-on evidence for shell state, local-only self-test, temporary-media cleanup, denied mic, absent device, hotkey conflict fallback, keyboard navigation, screen-reader labels, Windows DPI 125/150/200, A1 capture, A5 Telegram FIFO/callback behavior, and the exact-build A8 screenshots plus WACK. Capture sanitized logs and review notes for A2, A6 and A7 handoff.

## Acceptance Criteria
Reproducible exact-build evidence covers A1 UI and negative cases, real Telegram A5 default/callback/too-late behavior without duplicate playback, equivalent macOS parity, twelve reviewed EN/RU Store screenshots and reviewed WACK. Remaining A2/A6/A7 prerequisites are explicit; no secret, raw user audio or local private path enters published artifacts.
