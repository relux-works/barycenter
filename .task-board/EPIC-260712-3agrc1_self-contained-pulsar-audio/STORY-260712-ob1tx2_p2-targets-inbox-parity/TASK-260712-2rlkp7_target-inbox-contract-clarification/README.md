# Freeze Phase 2 target, inbox and transport-parity contracts

## Description
Close the remaining N-recipient, targeted-track, inbox and consent gaps without redefining Phase 1 identity, ACL, history or moderation.

## Scope
Define opaque selectable references for permitted Barycenters and Pulsar nodes, target-resolution authorization and deduplication, include-origin and exact targeted-track semantics. Define capability policy for Phase 1 nodes; inbox eligibility, ownership, TTL, lifecycle and manual replay; sender delete; stable opaque pagination; notification and zero late autoplay. Freeze versioned content-policy acceptance and reuse of Phase 1 secure callbacks, reports, blocks and delete. Resolve the B7 report ambiguity explicitly: distinguish reporter-local protection and any reviewed quarantine from moderator delete or disable so report cannot be abused as global denial of service.

## Acceptance Criteria
One reviewed contract gives API, storage, Windows, macOS and Telegram identical fields, enums, authorization, targeted-track, cursor, TTL, consent, mixed-version, replay and report or quarantine semantics. New members never discover old media, former targets follow only frozen retention, non-targets see nonexistence, a report cannot silently grant global censorship, and no task invents a second ACL, moderation or history model.
