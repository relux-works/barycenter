# P3 manual platform and capture capability acceptance

## Description
Hands-on platform selection and real-network verification for PTT input, live audio and capture processing.

## Scope
Run the store-safe hold-input matrix, live PTT real-network regression, Windows and macOS voice-processing probes and the C3 acoustic capability matrix in original order.

## Acceptance Criteria
Each supported platform and route is exercised on declared physical hardware with exact build and fixture hashes. Unsupported or degraded combinations remain explicit; results route back to engineering without silently changing code in this story.
