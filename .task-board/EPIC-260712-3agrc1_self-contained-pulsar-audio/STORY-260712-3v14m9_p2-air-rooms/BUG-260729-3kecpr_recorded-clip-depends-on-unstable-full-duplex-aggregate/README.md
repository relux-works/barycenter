# BUG-260729-3kecpr: recorded-clip-depends-on-unstable-full-duplex-aggregate

## Description
Production Pulsar 0.3.0 (958.2) still cannot record with the healthy default MacBook Pro Microphone. The ordinary recorded-clip flow enables AVAudioEngine voice processing, thereby constructing a transient input/output default-device aggregate even though clip recording is not full duplex. At 2026-07-29 17:29:31 CoreAudio invalidated aggregate device 429 and AVAudioEngine failed with OSStatus !dev (560227702), while the physical default microphone remained present at 48 kHz. The UI then incorrectly told the user to check the microphone and output route. Redesign the normal clip path so built-in/default microphones work without exposing processing-quality machinery.

## Scope
macOS ordinary recorded-clip capture composition, input device persistence/resolution, AVAudioEngine input-only startup, recording state/copy, EN/RU UI, focused and full regression coverage. Preserve live/full-duplex processing contracts, privacy, cue ordering, Air routing, capture safety ceilings, and dirty-worktree changes outside this bug.

## Acceptance Criteria
Pressing Record for an ordinary clip uses a microphone-only/input-only capture path and does not enable VPIO, construct or validate an output aggregate, or gate success on speaker/headphone route. A healthy built-in default microphone starts without a quality/limited-recording prompt even when input is 48 kHz and output is 44.1 kHz. Persisted microphone selection uses stable device identity or safely migrates/falls back to the current default instead of trusting ephemeral AudioDeviceID values. The one-button journey is Record -> recording -> Stop -> draft; internal quality/AEC/VPIO terminology is absent. Only permission denied, no microphone, selected external microphone disconnected, storage/cue failure, or a genuine input-only startup failure may block recording, with accurate localized recovery actions. Live/full-duplex paths retain their stricter processing policy. Deterministic tests cover built-in input, rate mismatch, stale device selection, no output dependency, failure cleanup/no partial draft, EN/RU copy, and regression of the 560227702 disappearing-aggregate receipt; focused/full tests, strict format/diff check, release build, independent review, production-signed installation, and real Mac recording smoke are required.
