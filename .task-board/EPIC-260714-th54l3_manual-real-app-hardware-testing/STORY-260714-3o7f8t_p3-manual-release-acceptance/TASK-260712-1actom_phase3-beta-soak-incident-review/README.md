# Run a resettable seven-day real Phase 3 beta

## Description
Collect the only valid soak evidence on the final reviewed build and feature-flag posture.

## Scope
Run seven consecutive 24-hour periods across named real multi-home participants with exact signed builds and separate live_ptt, E2EE, manual soundboard and automation cohorts or matrices. Review latency, jitter, capture, DSP, crypto fork or loss, automation, resources, reports and incidents daily. A stuck capture, runaway automation, key loss caused by defect, open critical or high finding, material tested-path code or config change, or missing daily evidence stops and resets the seven-day count after correction and review.

## Acceptance Criteria
Seven consecutive valid days have immutable daily logs, build and flag hashes and no prohibited incident. Every other incident is triaged with impact and disposition; any reset is visible and no pre-fix day is counted. The result is a pass or exact hold, never an estimate.
