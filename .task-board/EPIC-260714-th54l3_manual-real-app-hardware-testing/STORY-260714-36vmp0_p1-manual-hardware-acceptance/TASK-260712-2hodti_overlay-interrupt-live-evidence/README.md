# Capture real Windows and macOS A3/A4 evidence

## Description
Run the completed protocol and mixer through real output paths and produce reviewer-reproducible continuity and resume measurements.

## Scope
On real Windows and macOS installations, use internal Spotify-enabled test setups only for A3 and A4, send the specified ten-second overlay and interrupt, measure scheduled start, post-overlay timeline error, interrupt audible-position error, ring fill, underrun bursts, limiter hits, cancellation and recovery. Also prove standalone clip playback remains functional without Spotify. Record OS and app builds, hardware/output device, sanitized logs, screenshots or wave captures, exact steps and caveats for root and phase-one acceptance review.

## Acceptance Criteria
Evidence proves or honestly fails the 200-ms overlay and 500-ms interrupt tolerances on both platforms, shows no overflow, seek, skip or underrun burst, and distinguishes automation from human-observed output. It contains no credentials or user recordings, does not make Spotify part of the Store reviewer path, and gives exact reproduction steps plus owners for every miss.
