# Critical owner approval questions

## Description
A separate decision ledger for questions that require Ivan Oparin approval because they authorize irreversible publication, spending, legal commitments, external submissions or destructive production changes.

## Scope
During strict sequential engineering execution, record only genuinely critical owner decisions here. Continue reversible coding, unit tests, deterministic integration tests and documentation using explicit best-effort defaults. This epic is outside the original 205-task inventory and does not alter its progress counts.

## Acceptance Criteria
Each recorded question states the proposed default, impact, reversible work already completed and exact action that remains withheld. Resolved decisions preserve approver, timestamp and chosen answer. Engineering pauses only when the next action is irreversible or externally binding and no safe reversible work remains.
