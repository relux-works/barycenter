# Freeze Phase 3 gates environments reviewers and evidence contract

## Description
Create the immutable acceptance rubric before any integrated test or review result can be counted.

## Scope
Map C1-C7 and every section 21.4 gate to exact commands, hardware, platform pairs, speaker and headphone routes, live_ptt, e2ee_media, soundboard_cues and automation flag permutations, thresholds, fixture hashes and raw artifact paths. Name Windows and macOS hardware, two real home networks, beta homes, external cryptographic reviewer, independent domain reviewers, Store or legal owners and evidence retention. Define critical incident and build-change reset rules, partial promotion states, reviewer independence and the rule that missing input is blocked rather than passed.

## Acceptance Criteria
Every test, reviewer and beta task consumes the same dated pass or fail matrix and root-reviewed commit identity. C1-C7, boundedness, review, disclosure, rollback and seven-day rules cannot be weakened downstream. Missing hardware, people, authority or environments are explicit blockers with owners, and live PTT, E2EE, manual soundboard and automation have separable promotion decisions.
