# macOS main window and menu bar shell

## Description
Build a macOS main window and menu-bar shell that brings the self-contained audio path to parity with the Windows scope.

## Scope
Add a main window that complements the status menu with Create, Join, Try locally, presence, routing, now playing, history, settings and local controls. Include RU and EN strings, keyboard navigation, VoiceOver labels, non-color recording and DND states, and menu-bar shortcuts that keep the app usable while unpaired or degraded.

## Acceptance Criteria
macOS exposes the same primary Phase 1 actions and state model as Windows within the parity scope, without Spotify-first framing. The main window and menu bar keep recording, DND and error states legible and accessible and preserve a clear path into local self-test and settings.
