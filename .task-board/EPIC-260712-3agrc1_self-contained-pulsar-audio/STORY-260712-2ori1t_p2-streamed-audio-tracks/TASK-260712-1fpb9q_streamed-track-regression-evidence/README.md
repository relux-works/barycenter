# Prove B1 streamed-track performance and regressions

## Description
Close streamed-track implementation with cross-platform, network-fault, quota, revocation and compatibility evidence against the frozen hard gates.

## Scope
Run one-hour B1 plus maximum two-hour duration-bound tests, start before full download, p95 start, seek and skew, RSS and disk ceilings, pause or resume, repeated generation seek, rebuffer, network reset, no-range, corruption, cache eviction, delete or disable cache purge, quota and accounting reconciliation, coordinator and node restart and all Windows-Windows, Windows-macOS and macOS-macOS pairings. Cover queue or replace, Air join or leave, explicit targets, Phase 1 unsupported nodes and clip, overlay, interrupt and Spotify regressions. Include UI and Telegram contract fixtures and hand off scale or seven-day beta only to acceptance.

## Acceptance Criteria
Repo and hardware evidence proves B1 and streamed portions of B3, B6 and B7 with exact 5 s, 3 s, 100 ms and 200 MiB thresholds and duration-independent bounds. It catches full download, stale generation, audible-position error, late autoplay, cache revocation failure, quota mismatch and legacy regressions. Remaining 8 or 20 scale and seven-day beta steps are explicitly assigned, not marked passed.
