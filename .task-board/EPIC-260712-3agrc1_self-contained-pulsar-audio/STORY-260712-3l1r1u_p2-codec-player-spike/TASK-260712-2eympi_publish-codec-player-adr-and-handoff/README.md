# Publish a go or no-go codec and player ADR

## Description
Select an exact shippable Windows plus macOS combination only if measured, legal and operational hard gates all pass.

## Scope
Choose exact decoder versions and server variants from the comparative and license evidence; otherwise record no-go and the concrete next product decision. Record rejected combinations and why. Freeze node adapter and coordinator interfaces, sample and clock behavior, stream_variants and seek metadata, authenticated range contract, cache and ring ceilings, unsupported-target inputs, package and SBOM obligations, security/update ownership, fixture hashes and rollout assumptions consumed by streamed tracks and acceptance.

## Acceptance Criteria
The ADR names one complete production combination with exact versions and obligations that passes every hard gate, or explicitly blocks Phase 2 with no winner. It cannot average away a failed format, platform, license or Store constraint. Downstream tasks can implement without changing codec, container, integrity, seek, cache, timing or package assumptions.
