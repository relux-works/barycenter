# Independent Phase 2 codec, license and supply-chain review

## Description
Have a reviewer outside the codec implementation verify the ADR winner, exact packages and every hard gate.

## Scope
Inspect candidate evidence and ADR, exact versions and transitive licenses, patents or legal escalations, SBOM, signatures, Store and notarization posture, update and CVE ownership, hostile-input containment, range or integrity contract and reproducible packages. Re-run representative format, memory, seek and package checks and verify no failed mandatory gate was averaged away.

## Acceptance Criteria
An independent source-linked report either accepts one exact Windows plus macOS combination or blocks Phase 2. Critical and high findings are fixed and re-reviewed; legal unknowns remain explicit. No unsigned, downloaded, untracked or license-ambiguous decoder enters root review.
