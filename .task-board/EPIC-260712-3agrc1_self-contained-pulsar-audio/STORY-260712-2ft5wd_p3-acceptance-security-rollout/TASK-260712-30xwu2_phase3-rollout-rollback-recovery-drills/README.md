# Rehearse independent Phase 3 rollout rollback and recovery

## Description
Prove all Phase 3 capabilities can be enabled and stopped independently on production-shaped data.

## Scope
Apply additive migrations, deploy accept-but-disabled coordinator then reviewed nodes, enable internal live_ptt, e2ee_media, soundboard_cues and automation in the frozen combinations, and disable each independently. Rehearse old coordinator or node mixed fleet, rollback preserving rows and ciphertext, capture and automation emergency kills, token or device revoke, lost device, key fork or irrecoverable history, backup restore and public-claim rollback. Save exact commands, state snapshots and failure signatures and never make unavailable external steps appear passed.

## Acceptance Criteria
Operators can enable, hold or disable each capability without hidden coupling, data loss, secret exposure, stuck capture or automation and without leaving false UI or Store claims. Migrations and rollback are reproducible, recovery limits are honest and the exact reviewed artifacts are ready for independent operations review.
