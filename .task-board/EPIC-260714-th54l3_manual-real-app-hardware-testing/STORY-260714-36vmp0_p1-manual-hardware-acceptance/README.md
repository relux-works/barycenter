# P1 manual hardware and UI acceptance

## Description
Hands-on acceptance of the signed P1 application on physical Windows 10, Windows 11 and macOS systems after engineering builds and automated checks are ready.

## Scope
Run the Windows package lifecycle matrix, real overlay and interrupt audio-path measurements, and cross-platform UI, accessibility, DPI and local-capture verification. Use the original task acceptance criteria and original relative order.

## Acceptance Criteria
All three child tasks run against provenance-tracked signed builds on declared devices; screenshots, logs and measurements are sanitized and immutable. Missing hardware remains a manual-program hold and does not block EPIC-260712-3agrc1 engineering.
