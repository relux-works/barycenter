# Prove B5-B7 target, inbox and rights semantics

## Description
Close the story with adversarial storage, API, transport, UI, migration and mixed-version tests.

## Scope
Test forged opaque selectors, non-target API and range fetch, current-membership changes, N-recipient dedupe and no broadcast fallback, targeted tracks, include-origin, inbox eligibility and one-item uniqueness, TTL, pagination under inserts, local and targeted replay, delete or disable, DND, zero reconnect autoplay, consent version changes, secure Telegram callbacks and Windows or macOS parity. Cover Phase 1 clip fallback and visible unsupported stream targets, additive migration and rollback.

## Acceptance Criteria
Automated evidence maps B5-B7 and every story invariant. It catches target enumeration, current-membership ACL, duplicate or transitive delivery, cursor leak, stale or automatic replay, parallel moderation state, consent bypass and silent mixed-version behavior. Both platform combinations and Telegram share the same expected fixtures, with real-world proof named where automation is insufficient.
