# Implement the shared capture capability and diagnostics schema

## Description
Add one versioned privacy-safe state vocabulary across coordinator, Windows and Swift without owning platform presentation.

## Scope
Implement capability negotiation and node or live-session fields for route mode, processor enabled, accepted, degraded or unsupported reason, input level health, clipping or too-quiet guidance, reference unavailable, device transition and the two distinct ceiling states. Add Go, Windows and Swift mirrors, golden and malformed vectors, mixed-version downgrade and sanitized counters or structured logs. Never include audio, transcript, filenames, local paths, secrets or a remotely controllable capture flag.

## Acceptance Criteria
All protocol mirrors agree on bounded valid states and reject malformed or stale updates. Old nodes degrade honestly, metadata cannot open or resume a microphone, logs and telemetry contain no content and downstream Windows and macOS UIs can render the same semantics without pretending feature parity.
