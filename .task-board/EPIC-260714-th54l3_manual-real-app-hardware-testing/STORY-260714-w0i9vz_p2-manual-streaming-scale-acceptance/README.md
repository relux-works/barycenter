# P2 manual streaming, scale and beta acceptance

## Description
Hands-on integrated Phase 2 acceptance after streamed tracks, Air, target, inbox and rollout engineering are complete.

## Scope
Run streamed-track hardware regressions, Air and capacity acceptance, platform compatibility, migration and rollback rehearsal, rights and mixed-fleet acceptance, then the seven-day real beta in the original order.

## Acceptance Criteria
Every B1-B7, rollout and beta claim is tied to an immutable reviewed build and raw sanitized evidence. Failures are reported back to engineering; no synthetic or CI-only result is called a physical or real-beta pass.
