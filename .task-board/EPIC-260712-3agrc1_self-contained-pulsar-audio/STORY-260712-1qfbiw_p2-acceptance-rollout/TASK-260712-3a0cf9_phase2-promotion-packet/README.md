# Publish the reviewed Phase 2 promotion or hold packet

## Description
Close Phase 2 only with one evidence index that includes independent reviews, root decision, B1-B7, rollback, capacity and the qualifying beta.

## Scope
Update acceptance, runbook, architecture, quota, policy and rollout sources; index build hashes, reviewer reports and closed findings, B1-B7 raw artifacts, 20.5 metrics, migration or rollback commands, load results, seven beta days, incidents, quota decisions and feature flags. State exact enabled cohort and rollback owner. Produce a promotion or hold recommendation without calling an unavailable external step passed or losing rejected evidence.

## Acceptance Criteria
A reviewer validates every Phase 2 requirement from the packet alone. Docs and operational values match the accepted build, all critical or high findings and incidents are closed, pairwise compatibility is green and the seven-day gate is real. If held, the exact unmet criterion and next authority or environment step is named.
