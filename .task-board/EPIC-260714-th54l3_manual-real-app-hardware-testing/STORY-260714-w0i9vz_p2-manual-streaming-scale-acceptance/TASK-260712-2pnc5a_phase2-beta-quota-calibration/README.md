# Run the real seven-day multi-home beta and calibrate quotas

## Description
Operate the root-reviewed build in a real Air for seven consecutive 24-hour windows and turn observed usage into honest defaults.

## Scope
After all independent and root reviews plus B1-B7 preflight, enable Phase 2 on an approved real multi-home Air, preferably three Barycenters, with participant consent and an on-call or rollback owner. Monitor daily start, skew, seek, rebuffer, exact-once, queue, storage, processing, egress, quota and incident metrics; exercise normal track, clip, offline, join and leave use; record build or config changes as a beta restart unless the gate contract allows otherwise. Apply the critical-incident rubric, rollback triggers and privacy-safe incident log, then decide storage, egress, retention and alert defaults from measured evidence.

## Acceptance Criteria
Seven uninterrupted qualifying days finish with no critical incident and one immutable daily record each. Any critical incident resets the gate after fix and root review. Quota and alert choices cite measured usage and cost, residual guardrails have owners, and the beta exposes no participant content or identifiers in ordinary artifacts.
