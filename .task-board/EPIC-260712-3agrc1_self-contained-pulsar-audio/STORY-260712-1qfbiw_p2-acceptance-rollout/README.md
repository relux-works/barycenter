# P2 Acceptance, capacity and rollout

## Description
Prove B1-B7, capacity, migration rollback and real phase-two beta stability.

## Scope
Integrate phase two, execute B1-B7 and all non-functional gates, run 8-Barycenter/20-Pulsar synthetic load, platform combinations, migration and rollback rehearsals, storage/egress quota telemetry and a real seven-day multi-home beta before promotion.

## Acceptance Criteria
Every B scenario has reproducible evidence, performance limits pass, pairwise compatibility remains green, rollback preserves phase-two data and legacy service, operational docs and quotas match reality, and the real beta records seven days without critical incidents before the phase-two gate closes.
