# Probe exact bundled signed decoder candidates

## Description
Evaluate pinned self-contained decoder binaries or libraries that ship inside both packages with no first-run executable download.

## Scope
Build reproducible bundled prototypes for each shortlisted platform or shared candidate over the same range and cache contract. Exercise formats, VBR seek, scheduling, pause or resume, drain, cancellation, hostile inputs, RSS, disk and CPU. Capture every transitive binary, architecture, package-size, signature, MSIX redistribution, macOS hardened-runtime and notarization behavior, update and vulnerability path. Keep decoder work off render callbacks and apply process or FFI containment where required by the rubric.

## Acceptance Criteria
Both platforms have measured, signed and reproducibly packaged prototypes or exact rejection evidence. All required binary dependencies and notices are present, the package works offline after install, no unsigned or downloaded code appears, hostile input cannot escape the chosen containment, and no shipping or update assumption remains implicit.
